# Delhi Government School Data Analysis

## 📊 Project Overview

This project focuses on analyzing teacher workforce and workload data from a Synthetic Delhi Government School survey.

The analysis examines teacher availability, vacancies, workload, administrative support, teacher punctuality, unattended classes, and subject-wise staffing.

## 🎯 Objectives

- Analyze total sanctioned, filled, and vacant teacher posts
- Calculate the overall vacancy rate
- Analyze teacher attrition/retirement
- Examine replacement/guest teacher appointments
- Analyze daily teaching workload
- Study the impact of workload on classroom quality
- Analyze administrative support
- Examine teacher punctuality
- Analyze unattended classes
- Identify subject-wise staffing gaps

## 🗂️ Dataset

The dataset contains **103 teacher/post records**, including:

- 92 filled posts
- 11 vacant posts
- 2 teachers who left/retired during the previous 12 months

The dataset has been anonymized/synthetic for portfolio and learning purposes and should not be considered official government data.

## 🛠️ Tools & Technologies

- **Excel** – Data preparation and cleaning
- **SQL / DuckDB** – Data querying and analysis
- **Power BI** – Dashboard and visualization
- **GitHub** – Project documentation and version control

## 🔍 SQL Analysis

SQL queries are used to analyze:

1. Total sanctioned, filled, and vacant posts
2. Vacancy percentage
3. Teachers who left/retired
4. Replacement/guest teacher appointments
5. Average teaching periods per day
6. Workload and classroom quality
7. Administrative support
8. Teacher punctuality
9. Unattended classes
10. Subject-wise staffing and vacancies

## 📈 Power BI Dashboard

The Power BI dashboard will present key findings through:

- KPI cards
- Filled vs. vacant posts
- Subject-wise vacancy analysis
- Teaching workload analysis
- Administrative support
- Teacher punctuality
- Unattended classes
